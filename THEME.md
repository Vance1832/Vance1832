# Forensic Lens

One dominant terminal, followed by certificates, software stack, cybersecurity toolkit, projects, contribution activity and contact. Older unused assets are retained for easy theme changes.

- Hero: `assets/terminal_banner.svg`, 760 × 348. Violet `#c1abea`, charcoal `#0b111b`, muted blue `#a3b0c2`, success green `#92cdb1`.
- Hero loop: 12 seconds. The scan traverses the illustrative hex sample, highlights the bytes for `defend`, and gently illuminates three learning prompts. Identity and Security+ status remain visible throughout.
- No JavaScript, remote fonts, external SVG images, hover requirements or fake live statistics. Custom SVGs are self-contained; icons are embedded vector paths.
- Software certificate tiles use language logos only. Issuer identity remains in accessible text and verification links. Security+ has a dashed study tile, not an earned-certificate treatment or verification link.
- Software and toolkit icons glide gently sideways; every label remains visible. Reduced motion disables drift and scanning while retaining readable content.
- Completed cybersecurity certificate artwork is unchanged. Three projects use compact clickable cards; two supporting projects remain text links.
- The existing contribution snake and its workflow are retained. README URLs now point to the actual generated files on the existing `gh-pages` branch; the old `output` URLs returned 404.
- Icon sources and licensing: `assets/ICON_SOURCES.md` and `assets/licenses/DEVICON.txt`. Custom badges are display artwork, not issuer-issued badges.
- After editing an image, increment its README `?v=` value to refresh GitHub’s cache.

This profile describes a student learning journey, not professional incident-response experience or mastery of every tool shown. Nmap is explicitly marked as exploring; Security+ is in progress.
